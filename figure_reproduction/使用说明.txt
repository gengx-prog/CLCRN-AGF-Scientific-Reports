旧稿图表风格 + 本次修订数据
制作日期：2026-10-08

这套文件保留最初 SR 投稿稿件的图表形式、配色和布局，并用当前修订实验的数据重新绘制。
数据来自 2026-10-08 修订的 46 次训练：40 个主实验 + 6 个额外 mean-fusion 消融实验。
主实验是四任务、两种模型、每种五个训练种子。图形及误差条均来自当前记录，不沿用旧曲线形状。
此前恢复的旧实验包属于历史材料，未作为这些新结果图的数值来源。

建议先看：
1. preview/old_vs_new_results.pdf：六张结果图的旧版与新版并排对照。
2. preview/figures_and_tables_preview.pdf：8 张图与 4 张表的完整英文图注预览，共 10 页。
3. figures/：每张图的 PDF、SVG 和 PNG。
4. tables/：4 张表的 LaTeX、完整精度 CSV，以及两页预览 PDF。

保留与修改：
图 1 是概念插图，没有实验数值，原 PNG 原样保留。PDF/SVG 中也嵌入该原位图，不宣称是矢量图。
图 2 沿用浅色分区、圆角框、纵向结构，按实际代码修正 AGF 在 CLConv 之前的位置、两分支和门控公式。
图 3 保留热图；当前只包含 Persistence、Control、AGF 三种有新数据支持的方法。
图 4 保留蓝橙散点与黑色均值/误差棒，全部换成当前五种子结果。
图 5 保留四宫格与原曲线形式，使用当前 AGF 五种子均值和样本 SD；12 小时累计端点与表 1 一致。
图 6 保留分组柱形、颜色与斜线，比较同协议 Control/AGF。分成四个任务轴，避免混用不同物理单位。
图 7 保留灰底、四色和线型，纵轴改为同 64 个窗口干净输入基线上的相对 MAE 变化；图注披露采样和掩码方法。
图 8 保留横向分布、白色箱体和均值菱形，更新为四任务、每任务五种子、全部 657 个窗口和八个通道。
门控分布形状由真实 100-bin 直方图绘出，箱体/分位数是分箱近似；均值与总体 SD 使用精确记录值。
表 1–4 保留三线表、Times 字体和分组形式，并改为当前可追溯的数据及相应表注。
图 2–8 的 PDF/SVG 为矢量图；PNG 是查看用预览。

用于论文时：
manuscript_snippets/figure_captions.txt 提供英文图注。
manuscript_snippets/figures.tex 提供图片插入片段；路径相对于本文件夹。
manuscript_snippets/replacement_map.csv 对应旧图文件名与新图。
tables/table1.tex 至 table4.tex 含完整表注。
本目录负责图表复现；配套修订正文位于 ../Scientific_Reports_submission/main.tex 和 main.pdf，已经同步当前结果。
若将这些图表单独移入其他旧稿，该旧稿的正文仍须同步修改相应结果、实验定义和结论。
例如，新主实验仅湿度两项指标在八项比较的 BH 校正后显著；不能沿用旧文中其他任务必然改善的表述。
旧稿中的七种外部基线、旧单次实验、不同训练协议的柱子，不能只保留标签并填入新 AGF 数据。

数据与来源：
data/：当前修订的完整制图所需 CSV/JSON 快照。
source_data/：每幅图实际使用的值及中间汇总。
reference_assets/：原概念插图。
reference_previews/：旧结果图的参考截图，只用于视觉对照。
reference_code/：架构核对用代码摘录，不是完整训练仓库。
reference_configs/：46 次训练的模型配置，用于核实架构参数。
metadata/input_manifest.json：输入来源和 SHA256。
metadata/*.json：图注、数值验证、来源校验及风格修改说明。
validation/validation_summary.json：最终检查结果。
SHA256SUMS.csv：全包文件校验值（不含该清单自身）。

本机制图环境：
Windows；Python 3.13.7；Matplotlib 3.10.8；NumPy 2.4.2；pandas 3.0.0；SciPy 1.17.0；
PyMuPDF 1.28.2；Pillow 12.1.0；MiKTeX 的 pdflatex。
原图风格使用 DejaVu、Times 和 Windows 自带 Comic Sans MS。图 2 PDF 内嵌字体，SVG 字体转路径。
重绘图 2 时优先使用已安装的 Comic Sans MS；未安装时自动使用 DejaVu Sans。无需复制作者电脑字体文件。
制图及本次数值校验在 CPU 上执行，不要求 CUDA，也没有在本步骤重新训练模型。
此处记录的是本次图表制作环境；完整训练/评估环境仍以当前修订实验仓库的环境记录为准。

推荐从仓库根目录执行下列命令，在新目录中复现，保留原始文件：
python -m pip install -r figure_reproduction/requirements.txt
python reviewer_tools/reviewer_verify.py figures --output reviewer_figures

也可以复制本文件夹到新的位置，在复制后的目录中执行以下命令（会重写该副本中的生成文件）：
python -m pip install -r requirements.txt
python -X utf8 scripts/rebuild_all.py

需要系统已安装 pdflatex 并在 PATH 中，且可用 booktabs、graphicx、Times 等表格所需 TeX 包。
脚本先校验冻结输入，再重建八图、四表和预览，并重新执行数值一致性与文件格式检查。
这份轻量制图包包含已汇总的数据；从原气象样本重新训练/推断，应使用对应的完整实验仓库。
