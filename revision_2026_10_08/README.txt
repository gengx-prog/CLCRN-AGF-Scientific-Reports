CLCRN-AGF revision evidence and reproducibility package — 8 October 2026

CLCRN and CLConv are prior work by Lin et al. (AAAI 2022), based on https://github.com/EDAPINENUT/CLCRN . This work adds and evaluates an AGF input augmentation; adaptive graph/fusion design draws on Feng and Tassiulas, ASTTN (2022). It does not claim these existing ingredients or the CLCRN backbone as original.

CONTENTS
code/: byte-identical frozen training files (24 files; see provenance/training_source_manifest.json).
data/: full-precision fresh inference records, seed-level CSVs, statistical and figure source data for 40 primary plus 6 mean-fusion runs.
selected_runs/: one validation-selected complete checkpoint per run, the original full 100-epoch training history, configuration, summary and initialization/run manifests.
selected_checkpoints.json: portable paths, selected epochs, hashes and reference test scores.
provenance/: original environment, plan, data fingerprints and verification records. Absolute paths here are historical execution records; use the relative selected_checkpoints mapping for this package.
historical_context/: external published baseline audit and explicitly historical-weight inference microbenchmark. These are separate from the new accuracy study.

All 46 models completed 100 epochs, batch size 32, FP32, zero-inclusive loss/validation, no early stopping and no AMP/TF32. Five seeds (2021–2025) cover each primary task/variant; mean-fusion ablation uses three seeds (2023–2025) for temperature/humidity. Checkpoints were selected solely by the earliest minimum full-validation MAE. This archive contains the selected checkpoint only, not all 100 epoch files. The full epoch archive remains in the original experiment workspace. It is not a resumable copy of the entire original queue.

REBUILD TABLES AND FIGURES (NO WEATHER DATA NEEDED)
Install requirements.txt in a compatible Python environment, then from this directory:
  python rebuild_tables.py --output reconstructed
The fresh inference JSONs are recorded model outputs/diagnostics. Regenerating tables from them does not rerun model inference. Run provenance scripts retain the original paths; rebuild_tables.py is the portable entry point.

REEVALUATE A SELECTED CHECKPOINT (EXTERNAL WEATHER DATA REQUIRED)
  python evaluate_selected.py --data-root "PATH/Weather Bench_dataset" --run-id temperature_agf_2021 --device cuda:0 --output reevaluation_temperature_agf_2021
Use cpu if no compatible GPU is available. Full tests may be slower on CPU. Each task directory requires trn.pkl, val.pkl, test.pkl, position_info.pkl matching the recorded hashes. Data are obtained from the original CLCRN/WeatherBench sources cited in the manuscript. Raw weather arrays and upstream preprocessing products are not redistributed in this archive. Only trusted package checkpoints/pickles should be loaded. Hardware and dependency differences can affect reproducibility; the wrapper records any discrepancy instead of changing reference scores.

NEW TRAINING
  python code/run_revision.py --data-root "PATH/Weather Bench_dataset" --task temperature --variant agf --seed 2021 --epochs 100 --batch-size 32 --eval-batch-size 32 --patience 0 --protocol zero_inclusive --device cuda:0 --threads 4 --output new_temperature_agf_2021
Use a fresh output directory. The original run plan lists all task/variant/seed identities; original absolute commands are provenance, not portable commands. The same loss and validation protocol include zero and negative physical targets. Standardization uses training data only and casts raw arrays to float32 before standardizing.

The public materials for this revision are provided in release v0.2-retraining-20261008 at https://github.com/gengx-prog/CLCRN-AGF-Scientific-Reports/releases/tag/v0.2-retraining-20261008 . The current manuscript author is Xinchen Geng. This package does not claim journal acceptance or submission. The earlier v0.1-review release is historical and does not contain this new experiment grid.

VALIDATION: All 13 supplied CSV tables were regenerated byte for byte. A representative temperature AGF seed-2021 checkpoint was independently reloaded through evaluate_selected.py over all 657 test windows; MAE matched exactly and RMSE differed by 3.22e-10. This package test is one model, not a second full 46-model inference campaign. static_schematics supplies the two conceptual figures; rebuild_tables.py regenerates quantitative plots, not these conceptual drawings. The original audit script retains workspace paths and is supplied as an inspectable audit trail. See validation/portable_package_validation.json.
